# Fleet Lookup

Simple, fast **UK bus fleet / registration lookup** for Android using [bustimes.org](https://bustimes.org).

Perfect when you only have a fleet number or reg and want operator, type, livery and garage info quickly.

## Features

- Search by fleet code, fleet number or registration
- Clean detail view (type, fuel, double-deck, livery, garage, special features)
- One-tap open search on WM Bus Photos Forum
- Companion to **WMLiveBuses**, **NextStopRealtime** and **BusBashLog**

## Tech

Kotlin + Compose + Material 3 + Retrofit. Min SDK 26.

## Build

Android Studio → Sync → Run.
